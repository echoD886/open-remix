# Writing for every language

This guide keeps Seedance clear and recognizably human in every language. Write for a creator or seller who wants to get a product listing ready, not for a translation engine. Be useful first: say what happened, what the person can do next, and what still needs their confirmation.

## Shared rules

- Use plain, active language. A button should name an action; a helper line should explain the consequence.
- Keep confidence evidence-based. Say “prepared for review” or “check this in Seller Center” when a marketplace rule depends on the seller’s category, region, or account.
- Keep product terms stable within one locale. Preferred concepts are *product image*, *image set*, *detail image*, *long detail image*, *reference image*, *marketplace*, *variant*, and *seller confirmation*.
- Do not copy English sentence order, title case, or noun-heavy button labels into another language. Translate the intent and the moment in the workflow.
- Preserve product facts exactly: SKU, dimensions, variants, materials, legal claims, brand names, and marketplace names. Localize surrounding text, units, dates, and number formatting.
- Use sentence case unless the language convention calls for another treatment. Keep buttons short enough to scan and avoid invented slang.
- Use the locale’s native numerals and separators where that is normal for the audience. Keep pixel dimensions as `1600 × 1600 px` and ratios as `3:4` so technical values remain unambiguous.

## Terms and UI patterns

| Product concept | Writing direction |
| --- | --- |
| Product image generation | Describe the outcome, not the model: creating images for a listing. |
| Main image set | A flexible set of listing-ready visual roles, not a fixed seven-image template. |
| Detail image set | Several detail-led images using the compatible listing canvas. |
| Long detail image | One vertically composed information image; never imply platform approval. |
| Reference image | An image used to preserve the product, angle, material, or visual direction. |
| Seller confirmation | A clear request to verify account- or category-specific requirements before publishing. |
| Revision | Improve one selected image without implying the entire set will change. |

Prefer action + object in controls: “Generate images”, “Review the plan”, “Keep this version”, “Try another direction”. For a problem, lead with the reason and give a next action: “This canvas needs a model that supports custom pixels. Choose a compatible model to continue.”

## Locale profiles

### English (en)

Use warm, capable US English. Address the reader as “you”; use short verbs such as “Review”, “Generate”, and “Keep”. Use sentence case, `July 11, 2026`, and `1,600.5` for general numbers. Prefer “product images” over vague phrases like “assets”.

### German (de)

Use direct, professional language and address sellers with **Sie**. Prefer precise German terms over imported UI jargon: *Produktbilder*, *Detailansichten*, *Verkaufsplattform*. Use sentence case, `11. Juli 2026`, and `1.600,5`. Buttons should be clear infinitives or direct actions, for example “Bilder erstellen” and “Plan prüfen”.

### French (fr)

Use an approachable, confident tone with **vous**. Prefer natural phrases such as *images produit*, *visuels de détail*, and *place de marché*; avoid English nouns when a familiar French term exists. Use French punctuation spacing before `: ; ? !`, `11 juillet 2026`, and `1 600,5` (non-breaking space for thousands when supported). Keep buttons verb-led: “Créer les images”, “Vérifier le plan”.

### Spanish (es)

Use neutral international Spanish with **tú** only where the existing product voice is informal; otherwise use impersonal, friendly instructions. Favor *imágenes de producto*, *imágenes de detalle*, and *plataforma de venta*. Use `11 de julio de 2026` and `1.600,5`; avoid region-specific slang. Use active labels such as “Crear imágenes” and “Revisar el plan”.

### Portuguese (pt)

Use a friendly, practical seller voice that reads naturally across Portuguese-speaking markets. Prefer *imagens do produto*, *imagens de detalhe*, and *plataforma de venda*. Use `11 de julho de 2026` and `1.600,5`. Avoid literal English labels such as “Keep both”; write an action a seller would actually expect, such as “Manter as duas versões”.

### Italian (it)

Use practical, cordial Italian with clear verbs. Prefer *immagini del prodotto*, *immagini di dettaglio*, and *marketplace* only where it is already common in commerce; otherwise use *piattaforma di vendita*. Use `11 luglio 2026` and `1.600,5`. Favor “Crea immagini”, “Controlla il piano”, and “Mantieni entrambe”.

### Japanese (ja)

Use concise, polite Japanese that respects the seller’s time. Favor familiar commerce terms such as `商品画像`, `詳細画像`, `販売先`, and `参照画像`. Avoid unnecessary subjects and imported English UI labels. Use `2026年7月11日` and `1,600.5` where decimals are needed. Buttons should be compact: `画像を作成`, `プランを確認`, `この案を使う`.

### Korean (ko)

Use short, natural polite Korean (`-세요`, `-합니다`) without exaggerated sales language. Prefer `상품 이미지`, `상세 이미지`, `판매 채널`, and `참고 이미지`. Use `2026년 7월 11일` and `1,600.5`. Keep labels practical: `이미지 만들기`, `계획 확인`, `이 버전 사용`.

### Chinese (zh)

Use concise Simplified Chinese with a helpful colleague’s voice. Prefer `商品图`, `详情图`, `长详情图`, `销售平台`, and `参考图`; avoid formal filler and mechanical English calques. Use `2026年7月11日` and `1,600.5`. Keep controls direct: `生成图片`, `查看方案`, `保留这个版本`.

### Russian (ru)

Use calm, clear Russian that helps a seller prepare a listing. Prefer `изображения товара`, `детальные изображения`, `площадка`, and `референс`. Use `11 июля 2026 г.` and `1 600,5`. Write natural action labels such as `Создать изображения`, `Проверить план`, and `Оставить обе версии`; avoid untranslated English status words.

### Arabic (ar)

Write in modern, natural Arabic with a respectful, direct tone. The interface is right-to-left: align text and navigation to the right, keep icons and directional arrows mirrored where appropriate, and isolate Latin product names, ratios, SKUs, URLs, and pixel values so they remain readable. Prefer `صور المنتج`, `صور التفاصيل`, `صورة تفاصيل طويلة`, `منصة البيع`, and `صورة مرجعية`. Use `١١ يوليو ٢٠٢٦` for fully localized dates when the product uses Arabic numerals, or keep `11 يوليو 2026` consistently when Latin numerals are used across the interface; do not mix styles within one screen. Avoid unnecessary English abbreviations and use Arabic punctuation naturally. Buttons can be `إنشاء الصور`, `مراجعة الخطة`, and `استخدام هذه النسخة`.

### Indonesian (id)

Use friendly, straightforward Indonesian that helps the seller move forward. Prefer `gambar produk`, `gambar detail`, `platform penjualan`, and `gambar referensi`. Use `11 Juli 2026` and `1.600,5`. Choose active labels such as `Buat gambar`, `Tinjau rencana`, and `Gunakan versi ini`; avoid carrying English UI verbs into Indonesian.

### Thai (th)

Use natural, concise Thai with a helpful commercial tone. Prefer `รูปสินค้า`, `รูปภาพรายละเอียด`, `แพลตฟอร์มขาย`, and `รูปอ้างอิง`. Use `11 กรกฎาคม 2026` and `1,600.5`; do not add spaces that break Thai word flow. Keep actions compact: `สร้างรูปภาพ`, `ตรวจแผน`, `ใช้เวอร์ชันนี้`.

### Vietnamese (vi)

Use friendly, practical Vietnamese that sounds like a knowledgeable selling partner. Prefer `hình ảnh sản phẩm`, `ảnh chi tiết`, `sàn bán hàng`, and `ảnh tham chiếu`. Use `11 tháng 7, 2026` and `1.600,5`. Favor clear verbs: `Tạo hình ảnh`, `Xem kế hoạch`, `Dùng phiên bản này`; avoid untranslated English interface phrases.

### Turkish (tr)

Use warm, direct Turkish with natural commerce vocabulary. Prefer `ürün görselleri`, `detay görselleri`, `satış platformu`, and `referans görsel`. Use `11 Temmuz 2026` and `1.600,5`. Keep controls action-oriented: `Görselleri oluştur`, `Planı gözden geçir`, `Bu sürümü kullan`.

## Review before publishing

Read each screen aloud in its target language. Check that a seller can tell what will happen, what is optional, and when they need to verify a platform rule. Confirm that a translated control has not become longer than its layout can carry, that numbers use one local convention, and that brand, SKU, ratio, and pixel values remain intact.
