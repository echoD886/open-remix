# OpenRemix 管理后台完整设计方案

## 📋 目录结构

基于调研（GA4、Umami、Plausible、Mixpanel），设计以下7个核心模块：

```
/admin
├── / (overview)           - 总览看板
├── /analytics             - 用户行为分析
├── /funnel                - 转化漏斗
├── /retention             - 用户留存
├── /generations           - AI生成记录
├── /system-health         - 系统监控
├── /users                 - 用户管理（增强版）
└── /orders                - 订单收入
```

---

## 🎨 设计原则

### 1. 信息层级
- **顶部导航**：固定，快速切换模块
- **核心指标卡片**：最重要的4-6个数字，一眼看到健康度
- **主要图表区**：2-3个关键可视化
- **详细数据表**：可筛选、搜索、导出

### 2. 配色方案
```
成功绿：#22c55e
警告黄：#eab308
危险红：#ef4444
中性灰：#64748b
主色调：沿用现有的 primary 颜色
```

### 3. 响应式布局
- Desktop: 3列栅格布局
- Tablet: 2列
- Mobile: 1列堆叠
